# Task 1: problem statement draft

People holding a waste item may know that recycling is desirable yet remain uncertain about the material, the correct disposal route and whether a local return point accepts that packaging. General “plastic” or “metal” recognition does not establish PET/aluminum beverage-packaging eligibility. A misleading point recommendation can waste a trip or contaminate a collection stream.

The proposed initial audience is university students and dormitory residents. EcoVision addresses the decision immediately after a user photographs an item and keeps uncertainty visible. Existing DOA discovery/payment services are complementary infrastructure, not an absent baseline.

Evidence sources: [DOA packaging scope](https://doa.gov.tr/hangi-ambalajlar-iade-edilir), [DOA return points](https://doa.gov.tr/ambalaj-iadesi-nereye-yapilir), and the repository's dated point snapshot/manifest. No measured campus error rate, interview count or waste volume has been supplied. Add the author's real personal motivation and observations before submission.
