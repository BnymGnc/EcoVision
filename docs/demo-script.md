# Two-minute demo script

- **0–20 seconds:** show an existing beverage container and explain the sorting/return-point decision faced by a campus user. Do not claim interviews or a baseline that was not measured.
- **20–45 seconds:** capture/select one real photo. Show the real model/provider response. If the result is cached or analysis is unavailable, say so explicitly.
- **45–75 seconds:** complete the short DOA packaging check, show relevant DIM points and open actual route directions. Explain that source dates and unknown status are visible.
- **75–100 seconds:** show one quest or a genuinely performed user-declared action. Display application XP separately from scenario carbon estimates.
- **100–120 seconds:** explain AI's material-classification role, deterministic eligibility/routing and the proposed pilot metrics. Finish with limitations and next validation, not invented accuracy or waste savings.

Use a dedicated consenting demo account. No guest mode with access to personal production records has been added. Do not silently substitute a prerecorded response when the provider fails.
