# Two-minute demo script

- **0–20 seconds:** show an existing beverage container and explain the sorting/return-point decision faced by a campus user. Do not claim interviews or a baseline that was not measured.
- **20–45 seconds:** capture/select one real photo. Show the real model/provider response and score caveat. If the result is cached or analysis is unavailable, say so explicitly.
- **45–75 seconds:** use the direct DOA map button, show relevant DIM points and open actual route directions. Explain that generic plastic/metal does not verify PET/aluminum and that snapshot data is not guaranteed current acceptance. There is no packaging questionnaire in this result flow.
- **75–100 seconds:** open the material's sorting guide, show one practical rule and its source, then a quiz or quest reward. Application XP is not measured carbon savings. Do not demonstrate the removed action-entry screen.
- **100–120 seconds:** explain AI's material-classification role, deterministic eligibility/routing and the proposed pilot metrics. Finish with limitations and next validation, not invented accuracy or waste savings.

Use a dedicated consenting demo account. No guest mode with access to personal production records has been added. Do not silently substitute a prerecorded response when the provider fails.
